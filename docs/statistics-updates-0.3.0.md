# Статистика, приложения и обновления 0.3.0

Дата проверки: 5 октября 2026 года.

Статистика опирается на существующие дневные key_counts схемы 2. Добавлены чистые KeyStatistics/StatisticsFilter, фильтры приложения/группы/названия клавиши, объединение по дням и расшифровка выбранного дня. Результаты по каждому дню согласованы с общей суммой. Экспорт периода не сужается из-за выделения дня; отдельная команда экспортирует день. CSV записывается через временный файл, содержит BOM UTF-8 и защищает строковые формулы.

Читаемые названия приложений находятся в дополнительной таблице application_names, совместимой с базой схемы 2. Описание EXE и basename показываются вместе. Захватывается PID владельца фокусного HWND, а не PID окна на момент обработки очереди. Resolver удерживает информацию о живом процессе и проверяет время его старта против времени события, чтобы не переатрибутировать повторно использованный PID. Исходный путь EXE не записывается; SHA-256 пути используется как локальный fingerprint для отдельных копий. Абсолютная идентификация вложенных JVM/UWP/терминальных программ и защищённых процессов не заявляется.

OTA использует https://api.github.com/repos/saymonseo/TypingStats/releases. Выбирает опубликованную версию с Windows ZIP, проверяет HTTPS URL владельца репозитория, SHA-256 и размеры. ZIP проверяется до записи: traversal, повторяющиеся пути, symlinks, userdata и неполный пакет запрещены. Сборка содержит отдельный helper, который запускается из staging-копии, чтобы собственные загруженные DLL не блокировали замену.

Перед закрытием коллектора выполняются пауза/flush/backup. Файловая транзакция сохраняет предыдущие программные файлы и откатывает их при сбое. Перезапуск подтверждается именованным локальным event; нет подтверждения — новая версия завершается и выполняется откат. При неудачном старте сохраняется копия состояния базы после ошибки перед восстановлением предустановочной копии. Это относится к проверенным сценариям, а не гарантия восстановления при любых аппаратных сбоях.

Проверки:

- 37 автоматических тестов: прежние счётчики, даты/фильтры/экспорт, различение приложений, выбор версий, SHA-256, ZIP-пути, userdata protection, файловый rollback.
- Release build App и Updater без предупреждений и ошибок.
- Контрольный Windows pipeline и отрисовка восьми страниц, настроек и окна обновления.
- Фактический helper → замена файлов → ready handshake → запуск приложения на изолированной копии: 70 тестовых нажатий и portable.flag сохранены.
- Сбой целевого файла → rollback → перезапуск прежней версии на изолированной копии: те же 70 нажатий сохранены.

Рабочая пользовательская база в тестах не использовалась. Реальные игры, длительный soak-test и все конфигурации UAC/DPI остаются вне проверенной матрицы. Первый переход с 0.2.0 на 0.3.0 — ручная установка ZIP, поскольку прежний бинарник не имеет OTA-кода; путь истории при обычном режиме остаётся прежним.

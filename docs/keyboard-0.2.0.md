# Статистика клавиш 0.2.0

Добавлены режимы Text / Keys / Both, настройки repeat/injected и постоянные частоты отдельных клавиш. Keys учитывает доступные глобальные клавиатурные события до любой классификации символов или назначения клавиши приложением. W, Shift, Space, Enter, стрелки, Win и F-клавиши учитываются одинаковым способом без требования редактируемого поля. UI Automation в Keys отключается.

Schema 2 добавляет metrics.KeyPresses/KeyActiveMs, sessions.KeyPresses/KeyActiveMs и key_counts(local_date,app,profile,keycode,label,presses,repeats,injected). Частоты — дневные агрегаты, без key sequences и timestamps каждого события. Код физической клавиши — sc:XXXX с E0-префиксом для extended; при отсутствии scan code используется vk:XX. Для VK_PACKET содержимое scan code не сохраняется.

Начало keydown — одно нажатие; repeat включается отдельной настройкой. Сочетание Ctrl+V даёт события клавиш, а не объём clipboard. Автоповтор не меняет алгоритм подсчёта символов. Активное время клавиатуры измеряется отдельным объединением коротких интервалов, не временем удержания клавиши. Сессии могут содержать только нажатия и ноль текста.

Миграция схемы 1 создаёт backup и сохраняет прежние text metrics. Частоты прошлой версии не реконструируются. Backup/restore/clear и CSV поддерживают новый набор данных; повтор batch не удваивает частоты.

Проверки: 26 тестов Core/Storage; сохранение и восстановление частот; отдельные Ctrl/Enter; repeat/injected policy; VK_PACKET privacy; отсутствие текста при счёте клавиш; session/active intervals; реальная миграция схемы 1 с backup. Контрольный Windows pipeline: 20 учтённых событий, 17 групп клавиш, без добавления текста в Keys; нажатия моделируются метаданными, не вводятся в сторонние приложения. Реальные игры и античит-совместимость не объявляются протестированными.

Визуальная проверка: семь страниц, карта клавиатуры, таблица частот и настройки режимов. Исправлено обрезание числовых карточек при смене шрифта. Формат хранения меняется, но профиль пользователя и автозапуск не включаются автоматически.

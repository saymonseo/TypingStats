# Проверки статистики мыши 0.4.0

Реализация: существующий поток WH_KEYBOARD_LL/WH_MOUSE_LL теперь передаёт метаданные пяти mouse down-событий в общую очередь коллектора. Mouse move, up и wheel не сериализуются и не учитываются. Ошибка установки mouse hook теперь останавливает запуск с понятным сообщением, а не оставляет тихо неработающий счётчик.

Автоматические тесты проверяют декодирование пяти кнопок, игнорирование up/move/wheel, injected и enable policy, локальную полночь, независимость от клавиатурных метрик, фильтры и дневные суммы, экспорт, защиту CSV-ячеек, идемпотентное сохранение, backup/restore, схему хранения без координат и миграции 1/2 → 3.

Результат проверки 5 октября 2026: 45/45 тестов, сборка без предупреждений. Дымовой запуск и проверка всех вкладок завершились с кодом 0. Экспорт трёх форматов мыши выполнен на изолированной тестовой базе. Настройки мыши вынесены в начало окна; все пять кнопок видны в таблице без прокрутки при проверенном размере окна.

Реальный локальный Updater на отдельных копиях проверен в сценариях успешной замены/перезапуска и намеренной ошибки замены/отката. В обоих случаях сохранены 70 фиктивных клавиатурных нажатий, 15 кликов мыши и portable.flag. Проверка не обращалась к пользовательской базе и не публиковала релиз.

`--verify --data-dir <пустая тестовая папка>` проверяет Collector → Engine → SQLite → UI/CSV: 11 тестовых нажатий, 5 кнопок, 1 программный клик. В том числе учёт во всех трёх клавиатурных режимах, отказ от программных кликов по умолчанию и временное отключение мыши. Тестовые записи не добавляются в пользовательскую базу. Это контролируемые метаданные, не ввод настоящей мышью и не тест совместимости всех игр.

Реальный WH_MOUSE_LL успешно устанавливается при дымовом запуске. Снимки окон получаются через DrawToBitmap и проверяются визуально. Проверка не подтверждает получение всех событий в играх с античитом, на защищённом рабочем столе, от нестандартных драйверов или всех возможных кнопок игровых мышей. Не реализованы траектории, прокрутка, длительность удержания и различение устройств.

Для 0.4.0 подготовлена локальная Windows x64-сборка. Публикация релиза GitHub — отдельное действие; до публикации эта версия не предлагается через OTA.

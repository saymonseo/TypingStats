# Автозапуск 0.5.2

StartWithWindows хранится в settings.json и по умолчанию равен true. Отсутствующий флаг в настройках прошлых версий означает новый включённый вариант по умолчанию. Явный false сохраняется при загрузке и обновлении; повторный запуск удаляет оставшуюся запись TypingStats, но не регистрирует её заново.

Обычный запуск синхронизирует одно значение в HKCU\Software\Microsoft\Windows\CurrentVersion\Run. Команда содержит quoted EXE, --minimized и quoted --data-dir. Неизменная запись не перезаписывается. StartupApproved, HKLM и задания планировщика не изменяются. Не поддержанная Windows команда длиннее 260 символов вызывает понятную ошибку, а не тихую регистрацию неправильного запуска. Ошибка доступа к реестру не мешает сбору статистики и показывается уведомлением.

В настройках переключатель находится сразу после темы. Save применяет выбор и сохраняет его; при ошибке применения прежнее значение StartWithWindows восстанавливается. Smoke/verify/benchmark и test-host не создают настоящую запись Run. Проверка --verify использует fake store и временный HKCU-ключ, который не относится к автозагрузке и удаляется после теста.

Проверено: 52 Core/Storage-теста, 18 проверок автозапуска, видимость и состояние переключателя на рендере окна настроек. Включение по умолчанию, сохранённое отключение, повторное включение, ремонт пути EXE, миграция старых настроек, обработка отказа, тип REG_SZ и сохранение чужих значений прошли проверку. Настоящее значение Run TypingStats до и после тестов совпадает. Перезагрузка компьютера и вход в Windows в рамках проверки не выполнялись.

Схема статистики остаётся 3. Пользовательская история и реальные настройки установленного экземпляра не изменялись при тестировании.

# Проверки TypingStats 0.1.0

Дата: 29 сентября 2026 года.

## Выполнено

- Release build Core/Storage/App: 0 ошибок, 0 предупреждений.
- Console runner: 19 проверок, exit code 0.
- Unicode: RU, CJK, комбинируемый акцент, составные emoji, две части в каждой возможной позиции и поток по одному UTF-16 unit.
- Исправления: связанный Backspace, paste/navigation, ограничение остатка нулём, отрицательная дельта в следующей минуте, смена поля.
- Композиции: числовой commit/cancel, одинаковые результаты подряд.
- Активность: объединение интервалов, пауза, скачок wall clock, отдельные repeat/injected counters.
- SQLite: повтор batch, согласованные minute/hour/day rollups, backup/restore, CSV, отсутствие заранее заданного тестового текста в файлах.
- Контролируемый Windows pipeline: обычная раскладка преобразована через ToUnicodeEx, actor и база дали estimated=3, observed=2, net=4. Вставки не увеличили текст; финализация на 999 символов после paste во время незавершённой композиции не вошла в gross.
- Smoke startup: hook установлен, COM/UIA работает, горячая клавиша зарегистрирована, окно и все шесть вкладок отрисованы.
- Основное окно и настройки визуально проверены по снимкам собственных контролов; исправлены обрезанные подписи, toolbar и легенда графика.

## Короткая проверка ресурсов

Windows 11 build 26200, runtime 10.0.10, 14 logical processors. Наблюдение 30 секунд после 5 секунд прогрева, окно скрыто. Ввод на desktop не контролировался; это не чистый idle benchmark и не полный soak-test.

- CPU: 0,1376488% общей вычислительной мощности системы.
- Working set: 85,8867 МБ.
- Private bytes: 26,7148 МБ.
- Цель ТЗ ≤70 МБ working set не достигнута. Показатель private bytes не используется как подмена этой цели.
- После смены частого UIA polling на focus events CPU в этом коротком сценарии снизился с примерно 0,47% до примерно 0,14%; сравнение не является строго контролируемым benchmark.

## Не завершено

- Проверка кликов через Windows Computer Use: ожидание доступа к тестовому окну завершилось timeout. Пройденная отрисовка не означает, что все интерактивные действия прошли UI automation.
- Реальная матрица Блокнот/Word/Telegram/браузер/VS Code с заранее известным физическим набором.
- Реальные IME, emoji panel и software keyboard.
- Длительный 8-часовой запуск, аварийный kill во время commit, disk full, производительность на годовой базе и все DPI-конфигурации.
- Полное покрытие функций исходного ТЗ: ограничения версии перечислены в README и compatibility-report.

Версия передаётся как рабочая персональная 0.1, без заявления о завершённой универсальной точности.
